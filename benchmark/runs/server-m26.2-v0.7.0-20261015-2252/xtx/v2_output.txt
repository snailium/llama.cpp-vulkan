这张主板点位图（Board Layout / Schematic View）展示了典型的现代台式机主板布局，包含CPU插槽、内存插槽、PCIe插槽、M.2接口、音频/USB/LAN区域等。以下是**逐一列出的所有可见接口和主要元件**（按功能区块分类，便于理解）：

---

## 🖥️ 一、中央核心区域

### 1. CPU 插槽
- **CPU Socket**：位于板子右侧中部，带十字定位标记，是安装处理器的位置。
- 周围有供电相数电感（如 L21, L23）、电容阵列（C06x 系列），用于VRM供电。

### 2. 内存插槽（DIMM Slots）
- **DIMM1 ~ DIMM4**：共四条 DDR4/DDR5 内存插槽，垂直排列在 CPU 左侧。
- 每根插槽旁有对应的小元件（如 C08, C09 等滤波电容）。

---

## 🔌 二、扩展插槽与存储接口

### 3. PCIe 插槽
- **PCIe16X**：一条全长 PCIe x16 插槽，位于 CPU 上方，用于显卡。
- （可能还有隐藏的 PCIe x4/x1 插槽，但图中未明确标注）

### 4. M.2 接口
- **M2_1**：位于 PCIe16X 上方，靠近板边，通常支持 NVMe SSD。
- **M2_2**：位于 DIMM 插槽左侧，靠近板边，第二个 M.2 插槽。
> ✅ 两个 M.2 均带有固定螺丝孔位（小圆点）。

---

## 🎧 三、音频与网络区域（右上角）

### 5. 音频模块
- **AUDIO**：标有 “ADJ AUDIO” 的区域，包含声卡芯片（如 ALC1220/ALC4080 等）、运放（U3?）、耦合电容（C07, C08）、屏蔽罩轮廓。
- **CODEC**：音频编解码器芯片（如 Realtek ALCxxx）。
- **FAUDIO**：可能是前端音频接口或专用音频通路标识。

### 6. USB & LAN 区域
- **USB2_LAN**：集成 USB 2.0 控制器 + 以太网控制器（如 Intel I219-V / Realtek RTL8111）。
- **U530A**, **U531A**, **U532A**：可能是 USB Hub、LAN PHY、或相关控制 IC。
- **HDMI**：视频输出接口，通常由 CPU 或独显驱动（此处标注在右下角，应为板载 HDMI）。

---

## ⚡ 四、供电与辅助元件

### 7. VRM 供电模块
- **L21, L23**：CPU 核心/内存电感。
- **C061~C068**：CPU 供电去耦电容（MLCC）。
- **U64**：可能是 PWM 控制器或 MOSFET 驱动芯片。
- **U65**：可能是辅助电源管理 IC。

### 8. BIOS / Flash 芯片
- **U64** 或附近芯片（如 Winbond W25Qxx）：SPI Flash，存放 BIOS 固件。
- （部分主板会单独标出 “BIOS” 字样，本图未显式标注，但 U64 很可能是它）

---

## 📡 五、其他接口与功能模块

### 9. 前置面板接口（Front Panel Header）
- **PANEL**：位于左下角，包含 Power SW, Reset SW, LED, USB Front 等针脚定义。
- 旁边有 **C05**, **C06** 等滤波电容。

### 10. 音频输出/输入
- **FAUDIO** / **AUDIO** 区域已覆盖。
- 可能有 **Line Out / Mic In / Headphone** 接口（物理位置在 I/O 挡板，图中未显示）。

### 11. 视频输出
- **HDMI**：右下角明确标注，支持板载核显输出。
- （可能还有 DisplayPort 或 DVI，但图中仅见 HDMI）

### 12. USB 接口（后置 I/O）
- 虽未直接画出物理接口，但从布局看：
  - **USB2_LAN** 区域暗示有 USB 2.0/3.0 控制器。
  - 右上角可能有 Type-C / USB-A 接口预留位（需结合实物确认）。

### 13. 风扇接口
- **CPU_FAN**, **SYS_FAN**：通常在 CPU 插座附近或板边，图中未明确标注名称，但根据标准布局可推断存在。
  - （例如：CPU 插座上方/下方应有 4-pin PWM 风扇头）

### 14. SATA 接口
- **SATA**：左下角有 “SATA” 字样（实际是 “SAT A”，可能是排版问题），表示 SATA III 接口区域。
  - 通常有 2~6 个 SATA 口，图中未画出具体数量，但位置已预留。

### 15. 其他 IC / 元件
- **U47, U48, U49**：可能为时钟发生器、I/O expander、或传感器。
- **C01~C12**：各类去耦/滤波电容。
- **L1, L2...**：电感（用于各路供电）。
- **JST 连接器 / 排针**：如 “PANEL”, “USB2_LAN” 旁的排针，用于内部连接。

---

## 🧩 六、特殊标记与结构件

### 16. 固定孔位
- 四个角的大圆形开孔：主板安装螺丝孔（Standoff）。
- 多个小圆点：M.2、PCIe、CPU 插槽的固定螺丝位置。

### 17. 测试点 / Debug 接口
- **TP1, TP2...**：调试测试点（图中未明确标出，但常见于高端主板）。
- **Debug LED**：可能隐藏在某个区域（如 BIOS POST Code 显示位）。

---
