## Verdict

**PASS (quality/stability), no material improvement in dev b10883 over stable v0.4.0.**

- All 8 tasks green, zero crashes, outputs correct and complete.
- Short-context decode 35.5-35.9 t/s vs stable 37.8-38.8 (within run-to-run variance; t2 output length differed 8439 vs 6597 tok driven by sampling, not config).
- Agent decode 4.6-17.8 t/s vs stable 5.6-17.8 — same band; t3 slightly lower on dev because it ran ~12k deeper context.
- Vision decode 27.8-35.2 t/s cold (vs stable warm 22.3-37.5) — same tier; GPU offload confirmed (0 CPU layers).
- Recommendation: keep `:stable` = v0.4.0 candidate (already promoted). Dev b10883 adds no measured Vulkan gain on this suite; worth re-testing when upstream Xe2 FA/GEMM (#24406-8) lands. Issue #1 closed with promote; issue #2 (dev) holds dev results.
