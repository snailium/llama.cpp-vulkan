### 3. PCIe x16 插槽

### 5. USB 接口

- **LAN**（以太网口，通常在 USB2_LAN 区域下方或旁边）

- **VGA**（右下角，D-sub 15pin 接口轮廓清晰可见）

## ✅ 七、其他芯片与功能模块

### 13. 南桥 / PCH 芯片
- 位于 CPU 右侧下方，大型方形封装芯片（无明确标签，但通常是 Intel B660/Z690/B760/Z790 或 AMD X570/B550/X670 等）

### 14. 音频 Codec 芯片
- **CODEC**（右上角 AUDIO 区域内，靠近 M2_1）
- 通常用于处理模拟音频信号

### 15. 网络控制器芯片
- **SPH900**（位于 PCIe16X 下方中间位置）
  - 可能是 Realtek RTL8125/RTL8111 或 Intel I225/I226 等千兆/2.5G 网卡芯片

### 16. BIOS Flash 芯片
- **U64**（左下角，靠近 L23）
  - 通常是 SPI Flash，存储 BIOS 固件

### 17. 时钟发生器 / PLL
- **U65**, **U66** 等（分布在 CPU 附近）
  - 用于生成系统时钟信号

### 18. 超级 I/O 芯片
- 可能隐藏在主板背面或未标注，但正面通常有串口、并口、USB Hub 控制芯片
