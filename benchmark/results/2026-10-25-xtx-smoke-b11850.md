# XTX smoke: b11850 vs v0.7.0 — the qwen35 reshape refactor is a true no-op

**Date:** 2026-10-25 · **Card:** RX 7900 XTX (Vulkan/RADV) · Issue #14 candidate
**Images:** `:latest` = v0.7.0 (`620d222`) vs `server-dev-m26.2-b11850-20261024-0355`
(`sha256` per image pull; issue #14, build run 40060216970)

## Why only a smoke

b11706 → b11850 is 144 commits, of which **2 touch Vulkan** and both are no-ops for us
(`posix_memalign` for termux; non-contiguous `GGML_OP_SUM`, an op our graph does not use —
`qwen35` reaches `ggml_sum_rows`, not `ggml_sum`).

Exactly one commit touches **our model's graph**: `839a572a4 qwen: reshape output to 2d
instead of 3d`, editing `src/models/qwen35.cpp`. It merges two reshapes into one and drops
the closing reshape. That is claimed to be numerically equivalent — which is precisely the
kind of claim a smoke should settle rather than a source read.

## Result: byte-identical output, neutral speed

Greedy (`temperature 0`, `top_k 1`) so decoding is deterministic; identical production
config on both (ctx 131072, KV q8_0/q4_0, MTP4, mmproj on GPU, `n_gl 999`).

## Verdict

**Nothing in b11850 argues for promoting it, and nothing argues against it.** It is
behaviourally identical to v0.7.0 for our configuration, which is the expected outcome given
the delta. No full battery is warranted: the only change that could have affected us is
disproved by byte-identical greedy output.

Keep production on **v0.7.0 (`620d222`)**; there is no reason to take this candidate.

## Honest boundaries

1. **Three prompts, greedy.** Greedy makes text comparison exact, but it exercises one
   decoding path; a difference that only appears at temperature > 0 would not show. Given the
   change is a pure reshape, that is not a realistic failure mode.
2. **No vision task in this smoke.** mmproj was loaded and offloaded, and the load path and
   VRAM matched, but no image request was sent.
3. **No long-context request.** Graph-shape changes can matter at depth; this stayed well
   under 100 prompt tokens per request. The earlier 130k-depth work covers the production
   config, not this candidate.
