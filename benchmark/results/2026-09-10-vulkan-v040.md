### Agent deep-context behavior (the Vulkan weakness)
- t3 deep turns (cache 52-63k): decode 5.3-8.9 t/s; TTFT up to 125.8s for a 12.7k non-cached prefill at 101 t/s.
- Prefill on non-cached agent context: 110-133 t/s vs SYCL 337-430 (about 3x slower).
- Wall time: t3 26.5 min vs SYCL 7.4 min; t4 1m46s vs 56s. t5 was fast on both (44s vs 94s) because the Open-Meteo hint produced a short agent path.
- Draft acceptance is NOT the cause: Vulkan acc 0.55-0.90, equal or better than SYCL per task.
- Short-context decode (t1/t2, ≤43 prompt tokens) is close to SYCL (-13%/-18%), and equal to the older SYCL MTP4/128k numbers (30.8-36.4 t/s). The degradation is depth-scaling: mainline Vulkan still lacks the merged Xe2 FA/GEMM path (upstream #24406/#24407/#24408 open), so deep-context attention on Vulkan runs generic kernels — consistent with the pre-merge state documented for 2026-08-26.

### Vision (V1-V3)
- Cold E2E (CPU mmproj encode): 110.2s / 24.8s / 147.1s vs SYCL 109.5s / 18.9s / 140.4s — same tier.
- Warm-cache per-request timings: TTFT 0.19-0.29s, decode 22.3-37.5 t/s, draft-acc 0.556-0.688 — same tier as SYCL vision decode.
- Quality identical to llama.cpp baseline: all fine-grained numbers correct on V1; V2 XGA misread and V3 load-index 118S-vs-112S are documented single-digit OCR model/quant hard limits, not backend regressions.

### Cross-checks

The 2026-12-31 end is honestly reported as beyond ERA5 archive coverage (agent flagged it; not the 145.7-vs-mm unit hallucination seen on other rounds).
- Session-file request counts align with log segmentation (t3=20-22 depending on tool-turn counting, t4=5-6).

## Verdict

**Quality/stability: PASS — performance: HOLD for agent workloads.**

- Everything functional passes: 5 text tasks (2 direct + 3 agent) + 3 vision, all EXIT 0, complete, correct, zero crashes.
- Short-context direct decode (t1/t2 ~38 t/s) is usable and within ~15% of the SYCL baseline.
- **Deep-context agent decode and prefill are 3-4x slower than SYCL** (t3: 5.6 vs 22.3 t/s decode, 110 vs 430 t/s prefill, 26.5 vs 7.4 min wall). The mainline Vulkan Xe2 FA/GEMM gap (#24406-8 unmerged) is the likely cause; draft-acc parity rules out draft overhead.
- Vision and stability are on par.

Recommendation: do NOT promote this image as the production agent backend (SYCL v0.4.0 stays). The Vulkan candidate remains a valid stable/research build for short-context and vision use, and is a good base to re-benchmark once upstream merges the Xe2 FA/GEMM path.
